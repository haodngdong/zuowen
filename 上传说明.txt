【方式一 · 网页操作，全程点鼠标，2 分钟】

第 1 步 建仓库
  1) 浏览器打开 github.com，确认已登录 haodongdong
  2) 右上角 + 号 → New repository
  3) Repository name 填：zuowen
  4) 选 Public（免费版必须公开）
  5) 不要勾选 Add README
  6) 点绿色 Create repository

第 2 步 传文件
  1) 新页面中间有一行 "uploading an existing file"，点它
  2) 把本文件夹里的 index.html 拖进虚线框
  3) 下面绿按钮 Commit changes，点它

第 3 步 开 Pages
  1) 仓库顶部 Settings（齿轮）
  2) 左侧菜单往下找 Pages
  3) Source 那一行选 Deploy from a branch
  4) Branch 下拉选 main，右边保持 / (root)
  5) 点 Save

第 4 步 用
  等 1～3 分钟，刷新 Pages 页面，最上面会出现：
  "Your site is live at https://haodongdong.github.io/zuowen/"

  手机 Safari 打开这个地址 → 分享按钮 → 添加到主屏幕
  以后点图标就像 App 一样，不用开电脑

【方式二 · 命令行（如果你会用）】

  本文件夹已经初始化好 git 仓库，直接：
    cd ~/Desktop/作文复习-发布
    git push -u origin main

  会要求输入用户名和密码，密码处填 Personal Access Token
  （GitHub → Settings → Developer settings → Personal access tokens
    → Tokens(classic) → Generate new token，勾 repo，有效期选 7 天）

【常见问题】

Q: 打开是 404？
A: 还没部署完，等 1-3 分钟；或检查 Pages 里 Branch 是否选了 main。

Q: 想更新内容？
A: 重新执行第 2 步，覆盖上传 index.html 即可，地址不变。

Q: 会不会被别人看到？
A: 公开仓库任何人能访问，但没人会搜到。内容只是模板，不涉密。

Q: 国内会不会慢？
A: 偶尔会。建议同时在手机里存一份离线备份。
