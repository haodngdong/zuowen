【上传到 GitHub Pages · 4 步】

前提：已登录 github.com

第 1 步 建仓库
  1) 右上角 + 号 → New repository
  2) Repository name 填：zuowen
  3) 选 Public（免费版必须公开）
  4) 点 Create repository

第 2 步 传文件
  1) 新页面点 "uploading an existing file"（或 Add file → Upload files）
  2) 把本文件夹里的 index.html 拖进去
  3) 点绿色按钮 Commit changes

第 3 步 开网页服务
  1) 仓库顶部 Settings
  2) 左侧菜单找 Pages
  3) Source 选 "Deploy from a branch"
  4) Branch 选 main，右边保持 /(root)，点 Save

第 4 步 拿地址
  等 1 分钟左右，刷新 Pages 页面，顶部会出现：
  https://你的用户名.github.io/zuowen/

  手机上打开这个地址 → 分享 → 添加到主屏幕
  以后不用开电脑，随时随地能用

【注意】
· 仓库名如果是 zuowen，地址就是 /zuowen/
· 第一次可能要等 1-3 分钟才生效
· 更新内容：重复第 2 步重新上传 index.html 即可
